A personal recording archive

Keep the games.
Keep the memories.

Veo Backup Personal preserves sports recordings the owner is authorized to access, keeps a local video archive, and uploads selected games to the owner's YouTube channel.

Read the privacy policy Project operator on GitHub ↗

How the personal tool works

  1. 01 / BACK UP

    Save authorized recordings

    Download available full-game recordings from the owner's Veo account to storage on a personally operated server.

  2. 02 / VERIFY

    Check the local archive

    Track recordings, download progress, and media verification in a local database.

  3. 03 / UPLOAD

    Send selected games to YouTube

    Queue verified recordings, choose an optional playlist, and upload using the owner's Google authorization and configured visibility.

Google access stays
under the owner's control.

The tool uses Google OAuth to request permission to upload videos, manage their playlist assignments, check the authorized channel, and update recording dates. Google handles sign-in; the tool does not receive the owner's Google password.

Authorization tokens and operational records are stored on the owner's devices. The public website does not provide account sign-in, receive tokens, or host game recordings.

This is a personal-use project operated by the owner of the mhayes1426 GitHub account. It is not a public upload service and is not affiliated with Veo, Google, or YouTube.
